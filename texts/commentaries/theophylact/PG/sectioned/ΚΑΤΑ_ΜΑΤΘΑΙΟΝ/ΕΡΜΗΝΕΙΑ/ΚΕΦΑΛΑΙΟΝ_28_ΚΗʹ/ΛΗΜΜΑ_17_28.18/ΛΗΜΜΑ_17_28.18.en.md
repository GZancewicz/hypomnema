# Matthew 28 (ΚΗʹ) — Lemma 17 · Matt. 28:18

> **…Jesus, having come near, spoke to them, saying: All authority has been given to me in heaven and upon earth;[^1] (Matt. 28:18)**

*This lemma carries only the Gospel text, with no exposition of its own; Theophylact expounds "All authority has been given to me" at 28:20 (Lemma 19).*[^2]

[^1]: Greek OCR «προσελθὼν ὁ Ἰησοῦς ἐλάλησεν αὐτοῖς, λέγων· Ἐδόθη μοι πᾶσα ἐξο σία ἐν οὐρανῷ καὶ ἐπὶ γῆς·» — the garbled «ἐξο σία» is securely *ἐξουσία* ("authority / power / right"). *προσελθὼν* = "having approached / come near"; *ἐδόθη* (aorist passive) = "was given / has been given."
[^2]: Editorial note: the file contains no exposition, only scripture.
